# app_config

Reads the Wi-Fi network Vibe Mode shares with applications
(`mosaico_shared_get`): `app_config_load_wifi()` returns a validated SSID and
password, or clears its output. The shell uses it so Glimdock joins the same
network as Vibe Mode unless Glimdock's own settings name another.

Generated from the ESP-Mosaico project template.
